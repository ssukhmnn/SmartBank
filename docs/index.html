Smart Bank System

A console-based banking and ATM application written in C++ using Object-Oriented Programming.

  • Features
  • OOP concepts
  • How to run
  • Team

Features

  • Admin panel: create, modify, delete and view accounts, unlock accounts
  • ATM: PIN login, balance, deposit, withdraw, mini statement
  • Savings and Current account types
  • Account locks after 3 wrong PIN attempts
  • Data saved in a file between sessions

OOP concepts used

Concept Where it is used
Inheritance SavingsAccount and CurrentAccount inherit from Account
Abstract class and polymorphism Account has pure virtual functions; withdraw() behaves differently per type
Operator overloading += for deposits, << for printing an account
Exception handling Custom exceptions for low balance, wrong PIN, missing account
File handling Accounts saved and loaded using ofstream and ifstream

How to run

  1. Clone the repository from GitHub.
  2. Open a terminal in the project folder.
  3. Run .\build.bat to compile.
  4. Run .\bank.exe to start the program.
  5. Admin password: admin123
